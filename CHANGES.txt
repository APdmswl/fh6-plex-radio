FH6 Plex Radio Change Notice
============================

This file is a prominent modification notice for GPLv3 distribution.

Base project:
FH6 Universal Radio by g0ldyy
https://github.com/g0ldyy/fh6-universal-radio

Modified project:
FH6 Plex Radio

Modified version:
v0.1.5

Modification date:
2026-06-06

Summary of modifications:
- Focused the dashboard and runtime configuration on Plex playback.
- Added Plex library, artist, album, and playlist selection.
- Added Plex token/server configuration through the local dashboard.
- Added optional dashboard auto-open behavior on game start.
- Restored ffmpeg-based Plex decoding path for more stable playback.
- Increased the default audio ring buffer from 4 MB to 16 MB.
- Removed local-file and YouTube Music controls from the visible dashboard.
- Added attribution, source-code, modification, and third-party notices.
- Updated packaging and install scripts to include legal/compliance files.
- Prepared public GitHub-facing documentation and sanitized default Plex URLs.
- Documented that Codex 5.5 model was used as an AI development assistant.
- Documented ffmpeg as an external requirement for Plex playback.
- Merged upstream game-state playback handling for race/quick-station events,
  with Plex defaults set to avoid automatic queue advances unless enabled.
- Merged upstream radio stability handling for stale FMOD channels:
  auto-retune recovery, forced stereo DSP output, and soft audio clipping.
- Merged upstream metadata refresh behavior so the in-game HUD is updated only
  while the radio station is audible, avoiding stale sample-slot writes after
  pause/rewind-style transitions.
- Added forced metadata re-application after race/start station transitions so
  FH6 race HUD refreshes cannot leave the in-game radio card on game-supplied
  placeholder text.
- Improved Plex connection errors so WinHTTP failures include error codes and
  clearer local HTTPS/IP certificate hints in logs and the dashboard.
- Merged selected upstream runtime improvements from FH6 Universal Radio
  without re-enabling non-Plex dashboard sources.
- Added shared [general].ffmpeg_path fallback while preserving the existing
  Plex-specific ffmpeg path override.
- Added Plex playback options for ffmpeg loudness normalization and 5-band
  producer-side EQ.
- Made child process job assignment best-effort so playback can continue when
  Windows-compatible layers reject AssignProcessToJobObject.
- Expanded default local-file extension compatibility to match upstream
  defaults, while keeping the visible dashboard Plex-focused.
- Added paged Plex track catalog loading and a longer JSON receive timeout to
  avoid WinHTTP timeouts on very large music libraries.
- Re-pinned in-game radio metadata after FH6 overwrites the HUD strings during
  free driving, race transitions, or station state refreshes.
- Synced the latest upstream radio-stall timer catch-up while preserving the
  Plex-focused runtime and dashboard.
- Moved Plex ffmpeg process-spawn helpers into a shared subprocess module with
  safer PATH refresh and child-process launch behavior.
- Improved dashboard select styling with a custom arrow, hover state, and
  dark option colors.
